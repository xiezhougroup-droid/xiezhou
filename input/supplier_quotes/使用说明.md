# 供应商报价回收文件夹

采购员收到供应商报价后，把供应商返回的 Excel 放到这里。

建议目录结构：

```text
supplier_quotes/
  电线电缆包/
    供应商A-报价清单.xlsx
    供应商B-报价清单.xlsx
  配电箱柜包/
    供应商C-报价清单.xlsx
```

要求：

- 报价文件中保留 `正式报价清单` sheet；
- 不删除 `追溯号`；
- 供应商填写 `报价单价`、`报价合价`、`品牌/厂家`、`税率`、`供货周期`、`付款条件`、`报价备注`；
- 文件名建议包含供应商名称。

放好后运行：

```bash
./采购询价本地工作流/run_analyze_quotes.command
```
